# Rota da Grand Line

Um rastreador leve para acompanhar One Piece sem procurar a ordem toda vez. Interface em português, progresso salvo no próprio dispositivo, guia de filmes com ponto seguro para assistir, marcadores de filler, conquistas discretas e instalação como PWA.

## O que inclui

- Jornada por arcos em uma lista única, com busca e filtros.
- Sugestão do próximo arco e progresso geral.
- Fillers podem ser marcados como assistidos ou pulados.
- Filmes aparecem em uma lista própria, com episódio recomendado para evitar spoilers.
- Save local, sem cadastro ou sincronização com servidor. Dá para exportar/importar um arquivo JSON.
- PWA: depois de abrir uma vez com internet, o app guarda os arquivos essenciais e pode abrir offline.
- Instalação pelo menu do navegador em computador e celular compatíveis.

## Publicar com GitHub Pages

Envie todos os arquivos desta pasta para a raiz do repositório. Em **Settings → Pages**, selecione **Deploy from a branch**, escolha `main` e `/ (root)`. O link será `https://taleshns.github.io/one-piece-tracker/`.

## Guardar nos favoritos ou instalar

- Favorito: `Ctrl+D` no Windows/Linux ou `⌘D` no macOS. Em celular, use o menu do navegador e escolha **Adicionar aos favoritos**.
- Instalar: em navegador compatível, use **Instalar app** ou o menu **Instalar este site / Adicionar à tela inicial**.

O progresso fica neste navegador e neste dispositivo. Para trocar de aparelho, use **Exportar save** e depois **Importar save**.
